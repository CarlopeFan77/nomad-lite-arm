# NOMAD Lite ARM

A lightweight ARM64 offline knowledge environment inspired by
Project NOMAD.

The project is being developed initially for an Acer Chromebook
Spin 311 with:

- MediaTek Kompanio 500
- 4 GB RAM
- 32 GB internal storage
- ChromeOS Linux Development Environment
- Debian 12 ARM64

## Goals

- Run efficiently on low-power ARM64 hardware
- Provide offline access to reference material
- Support Kiwix and ZIM archives
- Use external storage for large content libraries
- Provide a lightweight web dashboard
- Add ARM-compatible self-hosted tools where practical

## Status

Early development.

Initial goals:

1. Establish ARM64 Debian environment
2. Test Kiwix
3. Build lightweight local dashboard
4. Add offline content storage
5. Evaluate additional Project NOMAD-style services
